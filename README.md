A custom rendering engine and experimental sandbox, built primarily for Linux using C++ and CMake.
The goal is to build a good-enough engine foundation for experimenting with real-time techniques for Global Illumination and other stochastic lighting.

Disclaimers:
As this is a personal project, I make no guarantees that the project will compile or run on other machines.
I am not looking for pull requests. I am trying to figure things out on my own rather than making a production-ready engine.
